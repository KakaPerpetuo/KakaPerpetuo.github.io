# Portfólio

Site pessoal em React (sem build, roda direto no navegador) com tema de terminal — verde, preto e cinza. Tem seção de apresentação, sobre (com foto), projetos e contato.

**[Ver demo ao vivo →](https://kakaperpetuo.github.io/)** 

## Estrutura

```
.
└── index.html   # site inteiro: HTML + CSS + React (via CDN), um único arquivo
```

Não tem `package.json`, não precisa de `npm install`. O React e o compilador de JSX (Babel) são carregados por CDN direto no `index.html`.
